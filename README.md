# AptAI GTM OS — Sales Enablement Demo

- **Week 2 — Activation:** Launch Campaigns (pre-flight, coordination, ramp-up)
- **Week 4+ — Optimization:** Outbound Analytics & Iteration

Single-file static HTML — open `index.html` locally or deploy to any static host.
